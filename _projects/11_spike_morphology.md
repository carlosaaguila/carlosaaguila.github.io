Code for extracting and analyzing the morphological features of interictal spikes — the amplitude, slope, sharpness, and slow-wave properties that change as epileptiform activity propagates from mesial to lateral temporal structures. These features are the inputs to the mesial-to-lateral gradient classifier used for localizing mesial temporal lobe epilepsy.
